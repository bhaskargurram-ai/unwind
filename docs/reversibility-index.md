# The Reversibility Index

The **Reversibility Index** is a public, browsable catalog of popular MCP servers and their tools, each rated by:

- **R-class** — where the tool sits on the [R0–R4 scale](concepts/taxonomy.md);
- **Blast radius** — how many entities a single call can affect;
- **Reversibility half-life** — the window within which the action can still be taken back.

It is meant to be **independently linkable and SEO-durable**: useful and quotable even to people who never install Unwind. It draws traffic on its own, and it *is* the [benchmark](benchmark.md) surfaced as a human-readable artifact.

!!! info "How it is generated"
    The index is produced by `unwind index`, which reads the catalog crawl in `bench/catalog/` and emits this table. Ratings are re-derived **per environment** (a tool is R1 on a git-backed tree and R4 on a versionless one), so the published index states the environment assumptions it was generated under.

    ```bash
    unwind index --catalog bench/catalog/ --env git-backed --format html > index.html
    ```

    We commit the crawler and content hashes, never scraped server payloads — so the index is reproducible without republishing anyone's data.

<script>
  (function () {
    var table = document.getElementById("ri-table");
    if (!table) return;
    var tbody = table.querySelector("tbody");
    var rows = Array.prototype.slice.call(tbody.querySelectorAll("tr"));
    var search = document.getElementById("ri-search");
    var classSel = document.getElementById("ri-class");
    var countEl = document.getElementById("ri-count");

    function cellNum(row, key) {
      if (key === "halflife") {
        var td = row.children[5];
        var v = td.getAttribute("data-hl");
        return v === "Infinity" ? Infinity : parseFloat(v);
      }
      return 0;
    }
    function cellRank(row) { return parseInt(row.children[3].getAttribute("data-r"), 10); }
    function cellText(row, idx) { return (row.children[idx].textContent || "").trim().toLowerCase(); }

    var headerIndex = { server:0, tool:1, verb:2, rclass:3, blast:4, halflife:5, inverse:6 };

    function applyFilter() {
      var q = (search.value || "").toLowerCase();
      var cls = classSel.value;
      var shown = 0;
      rows.forEach(function (r) {
        var text = r.textContent.toLowerCase();
        var rClass = "R" + r.children[3].getAttribute("data-r");
        var ok = (!q || text.indexOf(q) !== -1) && (!cls || rClass === cls);
        r.style.display = ok ? "" : "none";
        if (ok) shown++;
      });
      countEl.textContent = shown + " of " + rows.length + " tools (illustrative sample)";
    }

    table.querySelectorAll("th").forEach(function (th) {
      th.addEventListener("click", function () {
        var key = th.getAttribute("data-key");
        var type = th.getAttribute("data-type");
        var dir = th.getAttribute("data-dir") === "asc" ? "desc" : "asc";
        table.querySelectorAll("th").forEach(function (h) { h.removeAttribute("data-dir"); });
        th.setAttribute("data-dir", dir);
        var idx = headerIndex[key];
        var sorted = rows.slice().sort(function (a, b) {
          var av, bv;
          if (type === "num") { av = cellNum(a, key); bv = cellNum(b, key); }
          else if (type === "rank") { av = cellRank(a); bv = cellRank(b); }
          else { av = cellText(a, idx); bv = cellText(b, idx); }
          if (av < bv) return dir === "asc" ? -1 : 1;
          if (av > bv) return dir === "asc" ? 1 : -1;
          return 0;
        });
        sorted.forEach(function (r) { tbody.appendChild(r); });
      });
    });

    search.addEventListener("input", applyFilter);
    classSel.addEventListener("change", applyFilter);
    applyFilter();
  })();
</script>

## How to read a rating

- A green **R0/R1** row is safe for an agent to run autonomously — Unwind logs it and, for R1, keeps the pre-state to restore from.
- An amber **R2** row is compensable by a *different* tool; Unwind [synthesises and validates](concepts/compensation.md) that inverse before trusting it.
- An orange **R3** row can only be *mitigated* — the effect has become externally visible. Unwind escalates.
- A red **R4** row has no inverse and no mitigation. Unwind always interrupts the human before it runs.

The half-life column is the [novel dimension](concepts/taxonomy.md#reversibility-half-life-a-novel-dimension): `create_page` is recoverable for 30 days from trash, `send_email` for ~30 seconds, and `capture_payment` for exactly zero seconds once settled.

## Contributing a rating

Ratings come from the annotated corpus, not opinions. To add or correct a server, contribute to `bench/catalog/` and the [labelling pipeline](benchmark.md) — with ≥2 annotators, an ordinal inter-annotator-agreement check, and live-sandbox fidelity validation before any half-life or inverse claim is published. See [Contributing](contributing.md).
